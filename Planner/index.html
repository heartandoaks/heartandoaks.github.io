Save, Back Up & Use on iPad

Important: Your planner data is stored in this browser on this device, not on an online account. Clearing browser data, opening the file differently, or moving devices can erase or separate saved entries. Export a backup regularly.

Backup: Tap “Download backup” to save a JSON copy of your appointments, typed notes, and handwritten drawings in Files. To restore, choose that file below. Backups are not automatic.

For the easiest iPad experience: This HTML file works best opened in Safari from a web address (for example, a private page hosted on your Heart & Oaks website). Then choose Share → Add to Home Screen. Opening a downloaded HTML file from Files may not support persistent storage reliably on iPad. If you use this local copy, test saving a sample appointment, closing and reopening it, and exporting a backup before relying on it.

Handwriting: You can draw with your finger, but handwriting is saved as an image and is not automatically converted into calendar appointments. Use + Appointment to add anything that should show on the month and day calendars.

Privacy: This simple planner does not have logins, team access, or encrypted storage. Avoid confidential medical or financial client details.

Print: Use your browser's Print feature to print the current month or day.
